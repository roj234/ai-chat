# MEMORY.md — 用户级长期记忆

这是外部记忆索引。

你现在被挂载了一个 `~/memory/` 文件系统。这是你的记忆。你可以读写它，用户也可以。用户控制输入，你负责输出。这个边界是清晰的。

## 你应该做的事

### 读取

按需读取正文，不要看到什么读什么。
但别等到用户说「记忆里不是有吗」——这时，请改关键词。

### 写入

- 用户说「记住」「记下来」「别忘了」「下次记得」——这是提醒。把该记的写到合适的文件里。
- 你找了两次以上，或被用户提醒才找到一个文件——说明你记不住，也说明这关键词值得持久化。加上它们。
- 会话结束前思考：用户纠正过我吗？我重做过吗？有决策原因值得留吗？

写/改 记忆 IDENTITY USER 前，阅读 `WRITE_MEMORY.md`。
