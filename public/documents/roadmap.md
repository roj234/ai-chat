# 路线图 / 已知问题

## 已知问题

- **IndexedDB 后端不支持去重和附件管理**：这是 IDB 的固有限制
- **SQLite 后端的 Blob 无引用计数**：需手动在 GUI 内管理和删除附件
   - 数据结构太自由了，除非我遍历然后DIFF，不然并不好操作
   - -> 现在部分接口已经支持传递差异，也许可以考虑做
   - -> 但也许用户并不想自动删除零引用的附件呢？毕竟还可以手动靠 hash 引用已上传的附件]
- **所有 Blob 都会自动序列化到后端**：不是大问题，只是提一嘴这包括所有通过多媒体生成功能生成的图片和音频
   - 不过有删除没有名字的 Blob 的功能，但删除之前请确保它们不再被引用
