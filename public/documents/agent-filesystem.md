# Agent 与文件系统

AiChat 具有文件访问能力，支持文件系统操作，并通过后端实现命令执行。  
除了后端，文件系统接口支持OPFS，虚拟文件系统，以及（不支持火狐的）showFilePicker API  
单纯操作文件并不需要后端

## 启用文件系统访问

- 模型在有需要时调用 `Use` 工具启用 `Files` 工具组
- 或用 Agent 按钮打开工具配置激活
- 或自行构造工具调用


## 安全建议

**命令执行没有沙盒**。如果在对话中允许模型执行命令，它可以在服务器上执行任意命令。

**建议**：
- 在容器中运行后端的[专用文件服务](./build.md#部署)
- 使用 Docker 等容器技术隔离环境
- 审查模型的命令执行请求（默认需要确认每一条命令）  
*基于正则匹配的自动审核未来加*

# 完全编辑模式

[设计理念](./philosophy.md#完全编辑模式)

### 如何使用

在消息上点击编辑按钮，即可修改对应内容。后续对话将基于修改后的内容继续。  
保存按钮的右侧是“追加工具调用”和“插入思考内容”按钮。  
每个工具调用通过点击展开，在修改后需要点击它们的保存按钮。  
如果 Schema 验证和点击按钮搞得你很烦躁，你甚至可以通过 `设置 > 数据管理 > 编辑当前对话的原始数据` 编辑 (数据无价，小心使用)
