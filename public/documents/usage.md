# 使用指南

## 初次使用

新手引导会引导你完成设置，也可以看下面的步骤：

1. 移动端点击左上角打开侧边栏
2. 点击侧边栏左下角的扳手图标，进入设置面板
3. 转到`模型`Tab
4. 填写`API 地址` `API 密钥`、`模型 ID`三项（模型ID在填好前两项之后支持自动补全）
5. 点击底部的`测试`按钮，测试配置是否成功
6. 连接成功后会问你是否需要探测能力，通常点击是
7. 输入消息，Enter 或点击按钮发送  
使用 **Shift+Enter** 换行

PS：若你使用后端的SSE Proxy，需要先在`config.js`中配置服务商、代理服务器，之后可以在API 地址中填写 `@sse/v1`  
其中`@`代表相对于数据库后端基地址

> 能力探测确实有点兼容性问题。

## 远程使用
LLM 请求和文件访问总是由客户端，而不是服务器发起
- 在手机上使用时，所有的文件读写和 LLM 请求都需要消耗你手机的流量，它不是一个 “观察” PC 端行为的软件，它就是执行者

远控插件：
- 控制端和被控端需要同时启用它，被控端需要在设置中允许远程控制
- 目前部分功能，例如工具审批，需要你先拿到对话所有权再审批再恢复，比较麻烦
- 可选将执行模式设置为【后台】来节省被控端的资源占用

> 若你使用后端的 SSE Proxy 功能，并且你通过手机流量和公网访问，可以打开【消息引用】功能以节省手机发送到数据库后端的流量

## 斜杠命令

聊天输入框支持命令（**输入 `/help` 查看完整列表**）   
命令支持双引号转义，你可以使用 "\n" 来输入换行符  
此外，本项目的命令解释器非常宽容，你可以在双引号内输入真正的换行  
暂时不支持命令补全，因为我会尽可能把一切都做成 GUI  
命令通常只是临时的

## 界面功能

### 系统提示词
系统提示词的文本可以随时修改，影响所有**不使用助手**的会话  

> 使用助手的会话，系统提示词目前在创建对话时固定（但其中的变量会变），这个决定未来可能改变。  
> 如果你认为文档写的过于简略（显然），请用开发者选项的【编辑会话JSON】功能查看原始对象

你可以在系统提示词中使用占位符，例如 `{{:_xxx}}` 来引用名叫 `_xxx` 的预设中的系统提示词。  
内置占位符：tools mdfmt month 还有一些其他值  

```markdown
You are {{model}}, a helpful assistant.
{{modelPrompt}}
{{tools}}
<markdown-format>
{{mdfmt}}{{htmlTag}}
</markdown-format>
<date>{{month}}</date>
{{#AGENTS.md}}
```

> 默认极轻提示词：只有几百token的约束（来自 {{tools}} 变量注入），其它部分靠模型自己决定，够用但*可能*不够稳

> 激活文件访问工具后，会自动读取根目录的 AGENTS.md 并注入系统提示。你可以去掉 {{#AGENTS.md}} 变量来禁用

### 引用附件

输入框支持这两种语法，它们必须占满整行（前后不能有其他字符）：
- `![imageN]` 引用第 N 个附件
- `![blob](blobId)` 引用**上传到后端**的附件，附件长度必须为43个字符（这种字符串可以在附件管理里点击【复制】得到）

### 统计和文档

点击版权图标下方的【统计】链接可以查看和统计 API 请求的计费信息。
- 现已支持IndexedDB（为了性能，没有后端的情况下只保留10000条日志）。

点击【文档】链接可以打开软件内置的项目文档（就是你看的这个）

### 数据导入

- 支持导入 JSON 、JSONL 或 ZIP 格式的备份
- 支持导入 OpenAI 兼容请求的请求体
- 支持导入 SillyTavern（酒馆）角色卡、世界书、预设（JSON/PNG 格式）
- 插件可能注册更多支持的东西。

### 角色界面
- 在这里管理你的角色卡，世界书，预设，以及你的名字和介绍
- 角色卡，世界书，预设，都有响应式编辑器，它们在PC上更好操作，但移动端也能用
- 虽然我说的很简略，但是它们肯定比酒馆上手门槛低，而且好用

### 提示词
- 角色扮演时，建议把系统提示词改成 `禁用` (在下拉菜单里选择)
- 如果你用的预设里面有“人工思维链”，那么打开`解析响应中的思维链XML标签 (<think> 等)`也许是一个不错的选择
- 模型 > 高级配置中有一个`清理历史消息中的思维链`选项，你可以考虑改成`移除手动CoT`

## Markdown 渲染

AiChat 使用自研的流式 Markdown 解析器，支持：
- **正确的加粗**：正确渲染 `**"中文引号加粗"**`（按 CommonMark 规范不应加粗，但 LLM 输出中很常见）
- **KaTeX 数学公式**：`$...$` 行内公式，`$$...$$` 块级公式
- **Mermaid 图表**：流程图、时序图等
- **代码高亮**：基于 highlight.js 的语法高亮
- 大部分标准 Markdown 语法

## CORS 问题

由于浏览器安全策略，直接请求 LLM API 可能遇到跨域问题。解决方案：

1. **后端代理**：使用可选后端的 SSE 代理功能，自动处理 CORS
2. **反向代理**：在 LLM 服务前部署 Nginx/Caddy 添加 CORS 头
3. **llama-server**：自带 `--path` 参数可直接部署前端，无跨域问题
4. **安卓版本**：安卓版本的 LLM API 调用走 native 层，忽略 CORS（注：与后端的通信依然遵守 CORS）

## 安卓版本

安卓版提供与桌面版一致的核心体验，并：

- 支持拍照上传图片
- 文件访问采用 SAF API，不需要外部存储权限
- 自带开箱即用的 CORS Bypass

## 后端部署

有一些环境变量可以用
- `AINT_EXPERIMENTAL_BASH_GUARD`: 启用实验性 bash guard，减少 Agent 误删文件夹的可能性。会导致所有powershell命令执行失败。
- `AINT_AUTORESTART`: 启用服务端热更新（替换服务端文件后自动重启）
- `AINT_DEBUG`: 启用调试接口（查看生成请求的原始响应）
