# 使用指南

## 初次使用

新手引导会引导你完成设置，也可以看下面的步骤：

0. 移动端点击左上角打开侧边栏
1. 点击侧边栏左下角的扳手图标，进入设置面板
2. 转到`模型`Tab
3. 填写`API 地址` `API 密钥`、`模型 ID`三项（模型ID在填好前两项之后支持自动补全）
4. 点击底部的`测试`按钮，测试配置是否成功
5. 连接成功后会问你是否需要探测能力，点击是，它会帮你完成下面折叠部分
6. 输入消息，Enter 或点击按钮发送  
使用 **Shift+Enter** 换行

> 注：测试使用的是非流式调用，某些中转站居然这都不支持，以后可能会优化

## 远程使用
LLM 请求和文件访问总是由客户端，而不是服务器发起
- 在手机上使用时，所有的文件读写和 LLM 请求都需要消耗你手机的流量，它不是一个 “观察” PC 端行为的软件，它就是执行者
- 我加入了远程 RPC 解决这个问题，靠同步服务传递数据，但**目前没有代码实际使用**。
- 减少 PC 端耗电：
   - AFK 配置选【人不在】切到纯文本解析，不处理 markdown
   - 关闭【自动展开XX块】
   - 遵守 prefer-reduced-motions 规则
   - 别忘了打开唤醒锁阻止电脑睡眠（播放空白音频，未测试可靠性）

## 斜杠命令

聊天输入框支持命令（输入 `/help` 查看完整列表）：  
命令支持双引号转义，你可以使用 "\n" 来输入换行符  
此外，本项目的命令解释器非常宽容，你可以在双引号内输入真正的换行  
暂时不支持命令补全，因为我会尽可能把一切都做成 GUI

| 命令             | 说明               |
|----------------|------------------|
| `/help`        | 显示所有可用命令         |
| `/new`         | 创建新对话            |
| `/title <文本>`  | 重命名当前对话          |
| `/preset <名称>` | 加载预设配置           |
| `/continue`    | 继续上一条助手消息        |
| `/setprompt`   | 将预设的系统提示词固化到当前对话 |
| `/fsreset`     | 重置文件系统选择         |
| `/fsync`       | 同步文件系统更改         |

## 界面功能

### 系统提示词
我们支持通过类似技能的 frontmatter 语法指定新对话的默认工具
```
---
allowed-tools: tool_name
---
```
系统提示词的文本可以随时修改，但工具只在创建新对话时生效  
如果省略，那么新对话不包含任何工具（你依然可以点击工具按钮激活）  
你可以在系统提示词中使用占位符，例如 {{:_xxx}} 来引用名叫 _xxx 的预设中的系统提示词。  
内置占位符：think tools mdfmt date  
下划线开头的预设不会显示在快速选择器中。

### "继续消息" / Prefill / 回复预填充 (Assistant Message Prefill)

在生成AI回复前，先插入一段自定义文本
例如
```
user: 你好
// prefill
assistant: Hello
// generated
assistant: , how are you today.
```
我们假装AI生成了Hello，那么即便输入的是中文你好，模型也会用英文回复  
在本项目中，可以用来继续因为长度限制等原因而中断的消息，或者使用AntiSlop采样器。  
其他功能也许包括jailbreak，或者按指定要求生成文本（例如预填充` ```json\n `）

### Markdown附件引用

输入框支持这两种语法，它们必须占满整行（前后不能有其他字符）：
- `![imageN]` 引用第 N 个附件（文本、图片、音频）
- `![blob](blobId)` 引用之前上传到后端的附件，附件长度必须为43个字符

### 数据管理
导出

- 单个纯文本对话以 JSON 格式导出
- 多个对话或包含文）以 ZIP 格式导出
- 【导出对话】按钮行为：如果当前打开了对话，那么导出这个对话，否则导出全部对话

导入

- 支持导入 JSON 或 ZIP 格式的备份
- 支持导入 SillyTavern（酒馆）角色卡、世界书、预设（JSON/PNG 格式）

### 角色
- 在这里管理你的角色卡，世界书，预设，以及你的名字和介绍
- 角色卡，世界书，预设，都有响应式编辑器，它们可能在PC上更好操作，你需要仔细查看 title 来操作他们
- 虽然我说的很简略，但是它们肯定比酒馆上手门槛低，而且好用，只要你当写着“未实现”的功能不存在（主要是递归激活）

### 提示词
- 如果你玩角色扮演，建议你把系统提示改成`--- 回车 ---`，如果你用的预设里面有所谓的“人造思维链”，那么把`推理预算`改成手动就可以开思维链美化
- 移除历史思维链，基本上也是RP才需要动，你可以打开`仅手动CoT`

## Markdown 渲染

AiChat 使用自研的流式 Markdown 解析器，支持：
- **正确的加粗**：正确渲染 `**"中文引号加粗"**`（按 CommonMark 规范不应加粗，但 LLM 输出中很常见）
- **KaTeX 数学公式**：`$...$` 行内公式，`$$...$$` 块级公式
- **Mermaid 图表**：流程图、时序图等
- **代码高亮**：基于 highlight.js 的语法高亮
- 大部分标准 Markdown 语法

## CORS 问题

由于浏览器安全策略，直接请求 LLM API 可能遇到跨域问题。解决方案：

1. **后端代理**：使用可选后端的 SSE 代理功能，自动处理 CORS
2. **反向代理**：在 LLM 服务前部署 Nginx/Caddy 添加 CORS 头
3. **llama-server**：自带 `--path` 参数可直接部署前端，无跨域问题

## 安卓版本

安卓版提供与桌面版一致的核心体验，并：

- 支持拍照上传图片
- 文件访问采用 SAF API，不需要外部存储权限
- 不支持多页面协作（JSON 编辑器）

## Llama.cpp 模型管理插件

如果你使用 llama.cpp 的 router 模式，可以在 UI 内直接加载和卸载模型，无需手动重启服务。

## 并发对话

AiChat 支持同时进行多个对话，它们在后台独立运行，互不干扰。你可以在侧边栏切换对话，生成过程不会中断。
