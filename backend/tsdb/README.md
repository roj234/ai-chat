# @roj234/tsdb

为 AiChat 设计的日志存储引擎，取代关系型数据库
> 通用性是有代价的，我不通用，因此也不要付出那些代价

## 功能
- **通过 `id` / `owner` / `time` 三维度查询**原始Blob
- 最大支持 1TB 数据文件，64GB 索引文件，公元 20000 年时间戳
- 定长排序索引块，支持二分查找
- 通过简单的 WAL 支持时间回拨
- 支持修改 data 或删除数据库条目

## 优点
- 体积比 SQLite 的三个索引+数据小很多
  - 定长索引块的偏移即 rowid，不需要二级索引
  - 写入顺序 = 时间顺序，时间范围直接二分查找，无索引
  - owner 二分定位 + 缓存，无索引
- 查询性能比刚建的 SQLite 数据库都好很多
  - 而且 SQLite churn 多了之后（数据库很多表，不只是logs）会有碎片等问题导致性能下降
  - TSDB 永远是稳态性能
- 数据和索引块完全连续，范围查询结果为连续文件偏移，可实现零解码、零转换、零拷贝
- 逻辑简单，可在浏览器 VFS 抽象中运行

## 代价
- 修改和删除需重建受影响行后的数据库，且未实现崩溃保护（插入有）
- 数据长度字段为 8 位，只允许 255 字节内的数据
